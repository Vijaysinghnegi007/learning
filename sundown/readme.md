# Sundown Studio Inspired Landing Page

A responsive landing page inspired by Sundown Studio. This project was built using HTML, CSS, and JavaScript while learning animation concepts from Sheryians Coding School. I recreated the overall experience and added my own improvements, animations, and responsive design adjustments.

## Features

* Fully responsive design for desktop, tablet, and mobile devices
* Smooth scrolling using Lenis
* Scroll-based animations with GSAP and ScrollTrigger
* Horizontal scrolling cards section
* Custom footer with radial gradient effects
* Interactive and modern user experience
* Optimized layouts for different screen sizes

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* GSAP
* GSAP ScrollTrigger
* Lenis (CDN)

## What I Learned

While building this project, I learned:

* Responsive web design
* GSAP animations
* ScrollTrigger implementation
* Smooth scrolling with Lenis
* Horizontal scrolling effects
* Scroll-based storytelling
* Animation timing and user interactions
